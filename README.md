# coffee-cafe-website
A responsive Coffee Café website built using HTML, CSS, and JavaScript. Features include a modern landing page, menu section, gallery, customer reviews, contact form, and responsive design.

A modern and responsive Coffee Café Website developed using HTML, CSS, and JavaScript.

## 📌 Project Overview

This project is designed to showcase a coffee shop's online presence with an attractive user interface and responsive design.

The website includes:

- Home Page
- About Us Section
- Menu Section
- Gallery
- Customer Reviews
- Contact Information
- Contact Form
- Responsive Design

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts


## ✨ Features

### Home Section
- Attractive hero banner
- Call-to-action buttons

### About Section
- Coffee café introduction
- Café image display

### Menu Section
- 15 Coffee and Snack Items
- Pricing information
- Interactive menu cards

### Gallery Section
- Coffee shop image showcase

### Customer Reviews
- Customer feedback cards
- Modern card design

### Contact Section
- Contact information
- Contact form
- Form validation using JavaScript

### Responsive Design
- Mobile-friendly layout
- Tablet compatibility
- Desktop compatibility
